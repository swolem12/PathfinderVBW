# Fusion 360 media assets

Place course media in this folder and reference it from `src/content/fusion360.ts` with paths like `/PathfinderVBW/fusion360/filename.gif` after production.

Recommended asset naming:

- `solid-extrude-demo.gif`
- `solid-fillet-reference.png`
- `mesh-reduce-demo.gif`
- `sketch-constraints-reference.png`
- `guided-project-parameter-change.mp4`

Each media block already has alt text and a caption. If an asset is not ready, the lesson renders an accessible placeholder instead of a broken image.
